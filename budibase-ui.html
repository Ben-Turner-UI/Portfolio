Delivering core Budibase features: branches, permissions, and calculations

Context

As an in-house Product Designer at Budibase, I designed UI across many parts of the low-code platform, not only the automations builder (which has its own case study). Builders and admins need to wire workflows, lock down data, and work with live tables without leaving the product. My job was to turn those capabilities into interfaces that feel approachable on first use and still hold up for enterprise teams on self-hosted installs.

This page focuses on four elements I designed: conditional branches in automations, role-based permissions, calculated fields in views, and licensing flows for cloud, self-hosted, and air-gapped customers.

Automation branches

This feature allows you to create smart, automated workflows that can handle different situations. Think of it like setting up "if this, then that" rules. For example, "If an invoice is over £500, automatically notify a manager for approval. If not, mark it as paid." My design makes it easy to see and manage these rules in a simple flowchart, so you can build powerful automations without any code.

Role permissions

This shows how we allow administrators to control exactly who can see and do what inside their applications. It works like setting keycard access in an office: a manager might have a master key, while an employee's key only opens specific doors. My design provides a simple and clear way to manage these permission levels, ensuring that sensitive information is protected and team members only have access to what they need for their role. This prevents mistakes and keeps data secure.

View calculations

This is like having a smart spreadsheet built directly into your application. It lets you instantly perform calculations on your data, such as totalling up sales, finding an average score, or counting inventory, without having to export anything to a separate application. The interface I designed feels familiar and easy to use, allowing you to get quick insights and make faster, data-driven decisions right where you work.

Licensing and onboarding

Budibase ships as cloud-hosted, self-hosted, and air-gapped software. Each path has different constraints and expectations, but the product language had drifted apart. I redesigned the licensing and onboarding flows so customers could pick a deployment model, understand what they were activating, and get to a working app without opening a support thread. That work is mostly configuration UI rather than a single demo screen, so it is summarized in the table above rather than shown as a walkthrough here.
