Product UI collection

Here’s a selection of features and interfaces I’ve designed over the years, various complex UX problems with interesting and unique solutions.

Budibase

Automation branches

Automated workflows sometimes need to take different routes depending on what happens. For example, an invoice over £500 might need a manager’s approval, while a smaller invoice could move straight to the next step.

I designed a way for people to add these “if this, then that” conditions to each branch and see them beside the path they control. This kept the rules visible in the flowchart, making it easier to build and follow the workflow without writing code.

Budibase

Role permissions

Administrators need to control what people can see and do inside their applications. A manager might need to edit records and run actions, while another team member only needs to view information. The old settings presented permissions as a long list of switches, making access difficult to check.

I grouped permissions into Read, Write and Execute: viewing information, changing it and running actions. This gave administrators a clearer way to set access to data and queries for each custom role. I also brought role assignment into the same settings area, so they could define a role’s permissions and assign it to the right people in one place.

Budibase

View calculations

People often need to calculate values from their data without exporting it to a spreadsheet. This could mean working out a sales total or calculating a value from information already stored in a row.

I designed an interface for creating calculated fields using familiar, spreadsheet-style formulas, with JavaScript available for more complex calculations. Results appeared alongside the existing data, so people could check their calculations as they worked and use the new fields throughout their app.

Perforce · P4 DAM

Advanced filtering

This design builds on my experience creating advanced filtering interfaces for assets, databases and other complex datasets. It involved extensive research, with AI-generated browser prototypes helping me test interactions and iterate faster.

The main challenge was making active filters easy to understand while giving users full visibility and control over their selections. I placed removable filter pills directly inside the filter containers, so users could see and adjust their choices in context.

The interface brings together visibility, flexibility and ease of use. Products like Airtable, Jira and Notion offered useful references, but I felt each left parts of that experience unresolved. This was an opportunity to explore how those elements could work better together.
